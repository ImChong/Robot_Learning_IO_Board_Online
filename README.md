用交互式节点图对比开源机器人学习方法的**观测输入、动作输出与奖励函数**；支持维度与索引溯源、训练/部署视图切换，以及奖励曲线与参数交互。所有数据以开源实现为准。

Explore **observations, actions, and rewards** of open-source robot-learning policies through interactive graphs, with source-linked dimensions, training/deployment views, and tunable reward curves.
